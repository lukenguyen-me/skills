# 01: Record the parent feature branch name

**What to build:** After discovery, the run can name the parent integration branch from the conventional type, parent ticket id, and a short title summary.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] The parent branch is `{type}/{id}-{slug}` (type, issue number, hyphenated title), not the issue number alone.
- [ ] The branch name is not `main`, `master`, or `develop`.
